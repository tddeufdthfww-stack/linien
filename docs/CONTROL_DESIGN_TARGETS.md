# 控制与延迟设计目标（用户于2026-11-10补充）

- 应用：Cs原子852nm D2与894nm D1饱和吸收光谱锁频，未来可能MTS；PZT慢反馈用于低频漂移补偿。
- 初期快反馈单位增益交越频率设计100kHz，从10–30kHz实测调试起步；未来保留数百kHz至约1MHz Bare PID设计空间。全部为目标，不是已验证原子锁频带宽。
- R4a已经新增2个125MHz周期即16ns。优先相对R4a再增加0周期，后续额外0–16ns为优化目标，必要时先评估额外32ns以内方案；每次同时报告相对R4a和相对R2b累计周期，避免总量混淆。
- 不为低延迟牺牲时序收敛；报告功能、综合、route、最终STA/CDC/I/O签核、数字端到端总延迟及配置，不能互相替代。
- 电流驱动/PZT/光电探测/解调链完整响应未实测，没有真实可用闭环带宽或严格总延迟上限；这些缺测不阻止继续受控优化。
- 纯额外延迟相位=-360*f*dt度。100kHz下额外16/32ns为-0.576/-1.152度，1MHz下为-5.76/-11.52度；这只是传输延迟贡献，不是闭环稳定性证明。
