# R61b：DNA READ控制与CDC复位/错误协议的独立修复候选

R60仍冻结；R61a真实DNA时钟揭示hold，物理缓冲/局部重布可修hold但READ setup分别-.315/-.372ns，均不采用。完整R61a源功能已重新PASS。定向原桥native五组相位/100或125MHz测试确认：正常32事务/保持/快照及共同复位恢复PASS；单源复位后新请求超时FAIL、单目标复位后无请求重放旧写1次FAIL。不能将这些真实协议缺口用例外豁免。

1. DNA只增加READ控制FF，r复位1，cnt复位0，r'=cnt[0]?0:r；cnt从0递增至128停，故全部可达已知状态r==(cnt<2)。首个odd状态到cnt2时同步清READ，时钟/64次移位/CSR版本格式不变；完整新旧DNA原生逐拍比较和整数状态不变量检查在提交前执行。它不是反馈流水级。
2. bridge任一域复位使两端握手epoch清零；每域异步断言/两拍同步释放，避免旧toggle死锁和重放。链路恢复期间收到的SYS脉冲在源时钟域返回ACK+ERR，不静默丢失；已经在途但被复位取消的请求依赖原AXI约32拍超时SLVERR，不自动重放。正常ready后原数据/控制递推及地址/寄存器协议保持；仅异常复位恢复/启动具有明确新增ready等待2个本域边沿，不增加ADC→DAC/PID/IIR数据周期。
3. AXI响应在ACK当拍纳入sys_err_i并锁存，保持原B/R背压稳定修复；补定向SLVERR与复位/超时回归，原测试不削弱。Scope source_capture与真实ready接收条件一致，避免旁路缓存与payload错配。
4. CRG只把原单FF的PLL失锁同步采样改为异步断言/两拍同步释放reset，使PLL时钟停转时也能通知桥清状态；PLL/PS7/频率/相位/引脚与电气参数不变。相对旧reset释放多1个有效sys边沿；正常反馈延迟新增0，复位恢复契约变化单独记录，不冒称全瞬态旧版逐拍相同。
5. 先定向DNA/双桥正常与独立复位/恢复时请求错误/AXI错误和背压，再完整已有功能回归，重新生成CSR/XDC、全新综合和route（不复用R60物理时序）。DNA时钟在综合后按真实8ns主时钟生成并随DCP保存。ASR使用Migen标准实现带必要的精确同步器复位例外；不得全局cut异步数据。资源/STA/CDC/DRC按本轮实际结果判定，失败只归档不合并；I/O仍须独立板级预算，不把逻辑修复当作外部接口通过。
