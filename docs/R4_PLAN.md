## 实施前架构与数学契约

上一轮已比较A误差寄存1级/8ns、B误差与乘积2级/16ns。A后段仍包含无寄存DSP(约3.841ns)+积分carry+饱和与布线，8ns余量不足风险较高；本轮试B，单拍吞吐量不变，额外固定16ns。没有在积分反馈递推中插级。

以R2b的时钟边沿n采样事务T[n]=(signed输入、unsigned setpoint、running、Kp/Ki/Kd、reset、update_en)。S1捕获原w+1位模误差E及同拍有符号系数/reset；S2捕获原位宽/截断的P乘积、算术右移4的I乘积、D乘积及reset。有效位随CE推进2拍；所有前端级由sys125每拍运行。执行端用valid2消费事务，仍使用R2b原积分U/L饱和、原D历史递推、原pid_sum寄存和输出限幅。

设F是R2b每个有效事务的精确状态转换。乘法目的位宽/右移位置不变，故新执行端在n+2收到与原n完全相同的贡献和控制，满足S_new[n+2]=F(S_new[n+1],T[n])（bubble时保持）。连续及稀疏CE均为固定2个sys周期，不是2个慢速tick。P/I/D各自原有延迟保留，并共同延后16ns；不混用旧误差与新系数，不缩减26位混合符号误差。

reset CSR随同一采样事务延迟16ns执行，保持CE=0不清积分、CE=1 reset优先于饱和。事务按序执行，因此reset提交之后不会再消费reset之前的乘积。全局同步复位仍当拍清全部状态、两级valid/数据，取消所有在途事务；不将其延迟16ns。running在采样时门控误差，输入/增益/模式改变的PID效果都延后16ns，CSR总线本身仍立即按原协议写入/读回。启动先填充2拍，不宣称与无延迟R2b逐拍相同。

纯延迟相位损失360*f*16ns：100kHz=0.576度、1MHz=5.76度。未测开环传递函数、ADC/DAC/IIR/执行器共振和相位/增益裕度，不能证明激光锁频稳定。快速闭环中这是真实新增16ns反馈延迟，不因积分反馈内部未插级而归零。本轮无上板/激光操作。
